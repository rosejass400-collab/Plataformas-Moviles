# Challenge 01 - Mis Contactos

Aplicación React para listar, agregar y eliminar contactos.

## Ejecutar

1. Abrir la carpeta en Visual Studio Code.
2. Abrir una terminal.
3. Ejecutar:

```bash
npm install
npm run dev
```

4. Abrir la dirección que muestre Vite.

## Componentes

- `ContactForm.jsx`: agrega contactos.
- `ContactList.jsx`: muestra la lista.
- `ContactItem.jsx`: muestra y elimina un contacto.
- `App.jsx`: administra el estado, loader y datos iniciales.

## Challenge 02 - PWA

Aplicación de gestión de contactos desarrollada con React y transformada en una Progressive Web App (PWA).

### Funcionalidades

- Visualización de contactos.
- Agregar nuevos contactos.
- Eliminar contactos.
- Carga inicial de contactos.
- Imagen incorporada al componente principal.
- Instalación como aplicación PWA en dispositivos móviles.
- Ícono personalizado para la aplicación.
- Despliegue en Netlify.

### Aplicación publicada en Netlify

Puedes acceder a la aplicación desde el siguiente enlace:

### Instalación de la aplicación en el celular

#### Android

1. Abrir el enlace de la aplicación en Google Chrome:
   https://flourishing-faloodeh-da89ba.netlify.app/
2. Abrir el menú de los tres puntos ubicado en la parte superior derecha.
3. Seleccionar la opción **Instalar aplicación** o **Agregar a pantalla principal**, dependiendo de la versión de Chrome.
4. Confirmar la instalación.
5. Una vez instalada, abrir la aplicación desde el ícono que aparece en la pantalla del celular.

La aplicación funciona como una PWA y puede utilizarse desde el celular como una aplicación independiente.
