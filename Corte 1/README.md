# Challenge 01 - Mis Contactos

Aplicación React para listar, agregar y eliminar contactos.

## Ejecutar

1. Abrir la carpeta en Visual Studio Code.
2. Abrir una terminal.
3. Ejecutar:

```bash
npm install
npm run dev
```

4. Abrir la dirección que muestre Vite.

## Componentes

- `ContactForm.jsx`: agrega contactos.
- `ContactList.jsx`: muestra la lista.
- `ContactItem.jsx`: muestra y elimina un contacto.
- `App.jsx`: administra el estado, loader y datos iniciales.
